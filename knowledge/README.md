# 📚 Knowledge Base — Fazir Agency

Semua knowledge marketing yang Fazir jumpa dalam IG, Facebook group, WhatsApp, dan sumber lain disimpan sini oleh **Curator**.

## Struktur

| Folder | Untuk apa |
|--------|-----------|
| `inbox/` | Raw belum kategori |
| `psychology/` | Consumer psychology, bias, persuasion |
| `angles/` | Marketing angle, positioning, framing |
| `hooks/` | Hook, headline, attention-grabber |
| `copy/` | Copywriting contoh, ad copy, landing copy |
| `funnels/` | Struktur funnel, offer, upsell/downsell |
| `case-studies/` | Case study, brand breakdown |
| `competitor-swipe/` | Swipe file iklan/landing/content competitor |
| `ads-ops/` 🎯 | **Operasi media buying** — SOP, budget scaling, metric, tracking, account health, seasonality, post-mortem |

> 📌 `knowledge/` = **ILMU** (ilmu orang lain, dari IG/FB/group).
> `knowledge/ads-ops/` = **OPERASI** (macam mana Fazir sebenarnya jalankan iklan, apa jadi, counter dia).

## Format Fail

Setiap item = satu fail markdown `YYYY-MM-DD-slug.md` dengan frontmatter:
```yaml
---
source: Instagram (@nama)
platform: instagram
date: 2026-08-19
tags: [psychology, scarcity]
---
```

## Cara Recall

Tanya Curator (atau guna search dalam Obsidian):
- "Bagi aku 5 hook untuk supplement"
- "Apa psychology untuk pricing"
- "Ada tak case study competitor yang bagus?"
