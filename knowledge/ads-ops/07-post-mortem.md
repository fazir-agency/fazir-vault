# 07 — Post-Mortem

> Template untuk "**apa jadi → kenapa → counter**". Ni yang Fazir maksudkan bila cakap nak rekod decision & counter.

## Template

Copy blok ni bila nak rekod satu insiden / keputusan:

```markdown
---
date: YYYY-MM-DD
jenis: scaling | creative | tracking | policy | billing | stock | lain
kesan: RM___ | masa | reputasi
status: selesai | sedang-pulih | berulang
---

## Apa jadi
(4-5 baris. Fakta sahaja, tiada tafsiran dulu.)

## Angka
| Metrik | Sebelum | Selepas |
|---|---|---|
| Spend | | |
| CPA | | |
| ROAS | | |
| CTR | | |

## Kenapa (hipotesis)
1.
2.

## Counter
[Apa yang dilakukan. Live atau batal.]

## Pelajaran
[Satu ayat. Kalau tak boleh jadi satu ayat, belum faham lagi.]

## Ulang lagi?
[Ya/Tak. Kalau ya, apa tanda awal nak perasan?]
```

## Aturan

1. **Fakta dulu, tafsiran kemudian** — jangan campur
2. **Selalu ada angka** — post-mortem tanpa angka = cerita
3. **"Pelajaran" mesti satu ayat** — paksa diri fokus
4. **Rekod yang GAGAL lagi penting dari yang berjaya** — orang tak tulis kegagalan, sebab tu ulang silap
