# Social Content Templates

## TikTok / Reels Script
```
[0-3s] HOOK — Stop scrolling
[3-10s] PROBLEM — Relatable situation
[10-20s] SOLUTION — Product demo / before-after
[20-25s] CTA — Comment / Link in bio / Shopee
```

## Shopee Live Script
```
[OPEN] "Apa khabar semua... Hari ni ada special..."
[PROBLEM] "Ramai yang complaint pasal..."
[SOLUTION] "Ni produk kami, dah bertahun..."
[TESTIMONIAL] "Cik Aminah dari KL... dalam 2 minggu..."
[OFFER] "Hari ni special price... RMXX je..."
[URGENCY] "Stock tinggal 10 unit..."
[CLOSE] "Click link dekat description..."
```

## Facebook Ad Format
```
[IMAGE] Before-after / product shot
[HEADLINE] Problem → Solution in 5 words
[PRIMARY TEXT] 3 paragraphs max
[CTA BUTTON] Shop Now / Learn More
```

## Hashtag Strategy
- **Volume**: 5-10 hashtags
- **Mix**: 2 broad (weightloss), 3 niche (turunkurusmy), 1 brand, 2 trending
- **Language**: BM + English mix
